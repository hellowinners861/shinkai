# SHINKAI — 潜水艦・照射灯ビジュアル設計 V4

- Status: Ultra承認済み
- Date: 2026-08-19
- Scope: 潜航中の調査艇本体、回転式照射灯、サーチライト光束の表示
- Implementation owner: Luna Max (`gpt-5.6-luna`, thinking=`max`)

## 1. 目的と表現方針

潜水艦は兵器ではなく、未知の生物を傷つけずに観測する小型の深海調査艇として見せる。横長の耐圧殻、観測窓、小型スラスター、首振り式の観測灯により、スマートフォン上でも一目で前後と役割が分かるシルエットにする。

画像生成、外部画像、SVG、絵文字、外部フォントは使わない。PhaserのEllipse、Circle、Rectangle、Polygon、LineまたはGraphicsだけで描く。現行のゲームプレイ、操作、衝突判定、照射判定を変えないビジュアル改訂とする。

## 2. 変更しない不変条件

- 論理解像度450 × 800、プレイヤー初期位置、移動範囲を維持する。
- プレイヤー当たり判定は中心半径24pxのままとし、描画形状から物理判定を作らない。
- サーチライト判定原点はプレイヤー中心、距離260px、半角18度、最大回転240度/秒を維持する。
- 右スティック／IJKL、角度保持、識別進捗、優先順位、得点、章、大型生物イベントを変更しない。
- 描画順は `large creature(10) < species(20) < beam(30) < player(40) < chapter overlay(50)` を維持する。
- 衝突時の画面揺れから左右の仮想スティックを除外する。
- サーチライトの描画外縁と識別判定は、同じ距離・半角定数を共有する。

## 3. 潜水艦本体

### 3.1 シルエット

艇首は画面右、船尾は左とする。全パーツは原則としてプレイヤー中心から `x=-36〜+36`、`y=-26〜+26` に収め、移動端でも主要部が見切れないようにする。

背面から前面へ、次の順で構成する。

1. 船体影: 耐圧殻より2〜3px下へずらした暗い楕円。背景との分離だけに使い、強いドロップシャドウにしない。
2. 尾翼: 船尾側の上下へ短い安定翼。細い青緑の面とシアンの縁。
3. スラスター: 船尾端に小型リング、中央に暗いインペラ、後方へ短いシアン光。武器噴射のような長い炎にしない。
4. 耐圧殻: 約64 × 32pxの横長カプセル／楕円。暗い青緑の面、2pxの蓄光シアン輪郭、下半分に薄い陰影。
5. 艇首: 右端を丸い観測ドームとして読めるよう、短い継ぎ目とハイライトを置く。尖った魚雷形にはしない。
6. 上部構造: 中央よりやや後方に低い観測塔と短いアンテナ。最大高は26px以内。
7. 観測窓: 側面に大小3つまでの暗い円窓を置き、1pxのシアン縁とごく小さい反射を付ける。窓を均等な飾り玉にせず、前方の窓を少し大きくする。
8. 下部スキッド: 船体下へ短い支持脚と一本のスキッドを置き、海底調査艇らしさを加える。

### 3.2 色

| 用途 | 色 | 備考 |
| --- | --- | --- |
| 最暗部・影 | `#02090D` | 背景より黒く、完全な黒にはしない |
| 耐圧殻 | `#0A2D3A` | 主面 |
| 二次面 | `#164957` | 塔、尾翼、下半分 |
| 金属ハイライト | `#2A6A73` | 継ぎ目、上面 |
| 蓄光輪郭 | `#74F2D0` | 通常状態 |
| 窓ガラス | `#03131B` | 内部の暗さ |
| 窓反射 | `#8FEAF2` | 小面積のみ |
| 衝突警告 | `#FF6B5E` | 既存の0.45秒だけ |

シアンは輪郭・機器表示の小面積に限定し、船体全体を発光させない。暖色は照射灯だけに使い、艇の進行方向と照射方向を混同させない。

### 3.3 動きと衝突状態

- スラスター光は通常時だけ、経過時間に応じて低振幅でゆっくり明滅する。alphaの目安は0.42〜0.62、周期は約1.2秒とする。
- `prefers-reduced-motion` 時はスラスターalphaを0.52へ固定し、追加Tweenを作らない。
- 衝突中は耐圧殻、上部構造、スキッド、照射灯ヨークの輪郭を `#FF6B5E` にする。面色、窓、暖色レンズは維持する。
- 既存の赤い画面フィードバック、0.45秒の継続時間、無敵時間、揺れを変更しない。

## 4. 回転式照射灯

### 4.1 灯体

照射灯は艇側面中央に取り付けられた全周回転ジンバルとする。判定原点とのずれを避けるため、ジンバルの回転中心はプレイヤー中心と完全一致させる。

- 固定基部: 暗い円盤と細いシアンのリング。
- 回転ヨーク: 現在の `searchlightAngleRadians` と同じ角度で回る短い二股支持部。
- 灯体: 回転中心から照射方向へ約12〜16pxの短い真鍮色ハウジング。
- レンズ: 灯体先端に淡い金色の小円と白寄りの点状ハイライト。
- ビームはplayerより背面に置くため、船体が中心付近の光を自然に隠し、レンズから光が出ているように見せる。

灯体は右スティックを離した後も最後の角度を保持する。reduced-motion時は既存仕様どおり即時追従し、灯体だけに遅延や反動を加えない。

### 4.2 光束

現行の硬い中心線は廃止し、同じ暖色を重ねた四層の円錐へ置き換える。外層だけがゲームプレイ上の正確な境界で、内層は視覚表現である。

| 層 | 半角 | 長さ | alpha目安 |
| --- | ---: | ---: | ---: |
| 外縁 | 18度 | 260px | 0.025〜0.030 |
| 中間 | 12.5度 | 250px | 0.035〜0.045 |
| 内側 | 7度 | 238px | 0.055〜0.065 |
| コア | 2.8度 | 208px | 0.045〜0.055 |

- 色は全層 `#F1D58A` を基準とする。
- 4層の終端距離をずらし、一直線の平らな光端を避ける。
- 2pxの中心線、輪郭線、点滅、走査縞は描かない。
- レンズ付近だけ、小さな円形の暖色ブルームを許可する。生物アイコンやHUDが白飛びしないalphaに抑える。
- ビームの描画原点は全層ともプレイヤー中心とする。外層の260px・18度は識別判定の定数を直接参照する。
- ビームは時間で明滅させない。reduced-motionの有無で可視性や攻略情報を変えない。

## 5. 実装構造

`GameScene.ts`へパーツ描画を追加し続けず、コード描画を `src/game/submarineRenderer.ts` へ分離する。Phaserの型はtype importとし、純粋値・純粋関数をNode上のテストから読める構造にする。

最低限、次を公開する。

- 潜水艦の色、視覚範囲、パーツ順を表すreadonly定義。
- 潜水艦Viewを生成し、Player containerへ追加する関数。
- 現在角度、衝突状態、経過時間、reduced-motionをViewへ反映する更新関数。
- 四層ビーム定義と、中心・角度から三角形頂点を返す純粋関数。
- 通常／衝突時の輪郭色を返す純粋関数。

GameSceneは位置・入力・ゲーム状態を所有し続け、Rendererは表示だけを所有する。既存の `playerHull` だけに依存した衝突色更新は、SubmarineView全体の状態更新へ置き換える。scene cleanup後に灯体、beam Graphics、更新参照を残さない。

## 6. 受け入れ基準

- 390 × 844相当と320 × 568相当で、艇首、船尾、観測窓、スラスター、回転灯が区別できる。
- 右スティックを全方向へ回したとき、灯体とビームの角度が一致し、指を離しても角度を保持する。
- ビーム外縁と識別可能範囲に目視できるずれがない。
- 衝突時に艇と灯体が赤く反応し、左右スティックは揺れない。
- 既存の移動、衝突半径、燃料、識別、4章、大型生物イベント、スコアを回帰させない。
- reduced-motion時にスラスターが脈動せず、照準は既存どおり即時追従する。
- TypeScript、全Vitest、asset check、production build、`git diff --check` が成功する。
- Ultraが実際のスマートフォン相当画面で操作し、通常、斜め照射、衝突状態のスクリーンショットを確認して承認する。

## 7. 必須テスト

- 潜水艦の全視覚定義が有限値で、指定範囲内に収まる。
- 前方を示す艇首要素が+x側、スラスターが-x側にある。
- 四層の順序、半角、距離、alphaが本設計に一致し、外層がサーチライト判定定数と同じ値を参照する。
- ビーム頂点が常にプレイヤー中心で、0度、90度、180度、-90度の頂点が正しい。
- 灯体角度とサーチライト角度が一致する。
- 通常 `#74F2D0`、衝突 `#FF6B5E`、復帰後 `#74F2D0` の状態遷移。
- reduced-motion時のスラスターalphaが固定。
- 既存のサーチライト境界、大型生物照射時間、当たり判定テストがすべて維持される。
