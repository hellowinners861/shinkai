# SHINKAI — Ultra UIデザイン

- Status: Ultra承認済み
- Last updated: 2026-08-12
- Design name: Abyssal Field Console

## 1. コンセプト

「深海調査艇の耐圧殻に組み込まれた観測計器」。汎用ネオンSFではなく、暗い海、蓄光計器、酸化した真鍮の警告印、ソナー同心円で構成する。

- 情報の優先順位は、深度、燃料、進行状態、操舵、補助操作。
- 解像度、シェル、PCフォールバック等の開発用文言は表示しない。
- 背景、調査艇プレースホルダー、気泡、ソナー、計器線はPhaser／CSSの円、矩形、線、グラデーション、文字だけで描く。
- 画像生成、外部画像、外部フォント、hotlinkを禁止する。実在生物に見える仮素材も追加しない。

## 2. ビジュアルトークン

| 用途 | 値 |
| --- | --- |
| 最深背景 | `#02070B` |
| 深海背景 | `#04121A` |
| 計器パネル | `#071F2A` |
| 浮上パネル | `#0A2B36` |
| 低強度罫線 | `#27606A` |
| 蓄光／正常 | `#74F2D0` |
| ソナー／補助 | `#6BD9E8` |
| 注意／主CTA | `#F1B955` |
| 危険 | `#FF6B5E` |
| 主文字 | `#D9F0EE` |
| 補助文字 | `#86AEB0` |

- 背景は上部の青緑から下部の黒へ沈む一枚の深度グラデーション。明るい大面積カードは使わない。
- パネルは1px罫線、角の切り欠き、短い目盛線で一体の計器に見せる。主CTAだけ角丸6pxまで可。
- 見出しは端末内蔵の `Bahnschrift`, `Aptos Narrow`, `Yu Gothic UI`, sans-serif、数値は `Cascadia Mono`, `SFMono-Regular`, monospace。外部取得しない。
- タイトル字間0.16em、計器ラベル0.12em。全大文字は短い英数字ラベルだけに使う。

## 3. タイトル

- 上から `PELAGIC RESEARCH UNIT / DIVE LOG 00`、主題 `SHINKAI`、副題 `深海調査記録` を配置する。
- 中央は直径約230論理pxの観測窓。3本の同心円、十字目盛、低強度のソナー走査、コード描画の調査艇だけで構成する。
- 下部は細い罫線で区切る状態表示とし、`SYSTEM CHECK`、`操舵系統 / ONLINE`、`音響観測 / STANDBY` を基本文言にする。
- 操作説明は `左下の操舵環を動かして調査艇を操作`、主ボタンは `潜航を開始`。ボタンは横幅min(280px, 100%)、高さ56px以上。
- 320×568では状態表示を1行へ縮約してよいが、主題、観測窓、開始ボタンを省略せず、相互に重ねない。

## 4. プレイHUD

- 上部safe-area内の一段をテレメトリーレールとし、左から深度、燃料、音声、停止の順。タイトルや説明文を置かない。
- 深度は `DEPTH` と等幅数値 `0000 m`。燃料は `FUEL`、`100%`、水平ゲージを併記し、色だけに依存しない。
- 音声と停止は44×44 CSS px以上。狭い画面の可視ラベルは `SND` と `II`。アクセシブル名は `音声を切る／音声を入れる`、`一時停止／潜航を再開` と状態に追従させる。
- Canvas右端に薄い深度目盛を置けるが、深度計算や視野は変えない。
- 中央に低不透明度の同心円と走査線を置き、観測領域を空ける。装飾は原則alpha 0.22以下で、将来の生物を隠さない。
- 調査艇は船体、観測窓、尾部、前照灯を単純図形で分け、方向を判別しやすくする。当たり判定と移動範囲は変えない。
- 画面下の開発用説明文は撤去。右下の非操作表示 `DIVE ACTIVE`、`NAV / MANUAL` は320px幅で干渉する場合は非表示。

## 5. 操舵環

- 左下safe-area内の直径128pxを維持。二重の外周、52px以上のつまみ、上下左右4本の短い目盛を使う。
- 通常は暗い半透明面と蓄光輪郭、操作中は輪郭と中心点を強調する。発光は低強度。
- DOM、pointer処理、入力ベクトル、リセット条件は変えない。追加装飾はpointer-eventsを受け取らない。

## 6. 状態と文言

- 一時停止は観測領域を暗くし、中央に `PAUSED / 潜航停止`。既存ボタンまたはキーで再開する。
- 音声OFFは `aria-pressed`、可視ラベル、`OFF`または斜線の3点で示す。
- 横向き: 見出し `縦画面で潜航`、本文 `端末を縦向きにすると計器と操舵環が見やすくなります。`、ボタン `横向きのまま続ける`。
- 復帰: 見出し `潜航を再開しますか？`、本文 `安全のため操舵を停止しました。`、ボタン `潜航に戻る`。
- 案内カードは二重枠と小さな状態灯を持ち、幅min(360px, 100%)、主ボタン高さ52px以上。
- `html`は`lang=ja`。主要文言とARIA通知は日本語を正とし、英語は短い計器ラベルに限定する。

## 7. モーション

- 反復は3.6〜4.4秒の低強度ソナー、6〜10秒の少数気泡、緩い状態灯だけ。点滅は1秒3回未満。
- 開始時の移動量はタイトル8px以内、ボタン12px以内、200〜500ms。大きなズーム、全面フラッシュは禁止。
- `prefers-reduced-motion: reduce`では反復、移動、脈動を停止して静止表示にする。

## 8. Luna Max実装範囲

- 編集可能: `index.html`、`src/style.css`、`src/main.ts`、`src/scenes/TitleScene.ts`、`src/scenes/GameScene.ts`、UI文言に直接関係するテスト。必要ならREADMEの画面説明のみ。
- 変更禁止: ゲーム定数、入力計算、ライフサイクル状態遷移、生物データ、研究CSV、画像、ビルド／配信設定。
- 開始、タッチ移動、WASD／矢印移動、P／Esc停止、音声設定保存、非表示時停止、明示復帰、横向き継続を維持する。

## 9. 受け入れ基準

- 320×568、390×844、430×932でタイトル、HUD、2ボタン、操舵環、調査艇、主CTAが重ならずsafe-area内に収まる。
- 横画面とPCで450×800の固定視野を保ち、案内カードが欠けない。
- 操作対象44×44 CSS px以上、開始ボタン56px以上、主要文字はWCAG 2.2 AA相当。
- `MOBILE SHELL`、`MOBILE VERTICAL SHELL`、解像度説明、PCフォールバック説明が表示に残らない。
- 外部通信、生成画像、外部画像、外部フォント、新しい実在生物表現を追加しない。
- `npm run typecheck`、`npm test`、`npm run build`が成功する。
- タイトル開始、プレイ、停止／再開、音声ON/OFF、復帰案内、横向き案内でコンソールエラーがない。
