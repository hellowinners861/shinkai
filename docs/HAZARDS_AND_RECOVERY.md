# SHINKAI — 岩・衝突・燃料回復 縦切り設計

- Status: Ultra承認済み
- Last updated: 2026-08-12
- Scope: 岩、衝突ダメージ、無敵時間、燃料回復カプセル、即時フィードバック

## 1. 目的

自動潜航中に「避ける」「当たると燃料が減る」「回復を拾う」という最小ゲームループを成立させる。今回は実在生物、スコア、図鑑、正式な結果画面、画像素材を実装しない。岩と回復カプセルはロードマップで許可したコード描画の仮図形とし、生物に見える仮素材は作らない。

## 2. プレイ仕様

- 岩と回復カプセルは画面下から現れ、世界が上へ流れる向きに移動する。艇は従来どおり上下左右へ操舵できる。
- 出現は潜航の経過秒を基準にした決定的なスケジュールとする。端末性能やフレームレートで出現順が変わらず、同じ潜航では同じ時刻とレーンに現れる。
- 岩は最初の1個を1.5秒で生成し、以後5秒ごとに生成する。横位置は中央、左外、右外、左内、右内の5レーンを順番に循環する。
- 回復カプセルは最初の1個を9秒で生成し、以後20秒ごとに生成する。横位置は中央、右内、左内を順番に循環する。
- 岩は毎秒78px、回復カプセルは毎秒70pxで上へ移動する。生成Yは680、破棄Yは96とする。
- 同一フレームで複数の予定時刻をまたいだ場合も必要な個数を欠落なく生成する。停止、ライフサイクル停止、横向き案内、非表示中は出現時刻も移動も進めない。
- 画面内の岩は最大6個、回復カプセルは最大2個とする。上限時は古い画面外要素を優先して破棄し、無制限にGameObjectを増やさない。

## 3. 衝突と燃料

| 項目 | 値 |
| --- | ---: |
| 岩1回の燃料ダメージ | 10 |
| 衝突後の無敵時間 | 1.0秒 |
| 回復カプセル | +25 |
| 艇の判定半径 | 24px |
| 岩の判定半径 | 22〜28px（見た目ごとに固定） |
| 回復の判定半径 | 22px |

- 判定は円同士の距離判定とし、見た目より不当に大きくしない。
- 岩に接触すると燃料を10減らし、その岩を即時破棄して1秒の無敵状態へ入る。無敵中の別の岩はダメージを与えず通過する。
- 回復カプセルに接触すると燃料を25回復し、最大100で丸めてカプセルを即時破棄する。満タン時でもカプセルは回収扱いとし、`FUEL FULL`を表示する。
- 通常消費、衝突、回復は同じ`DiveProgressionState`を正本として更新する。燃料0なら既存の`depleted`へ、深度6,000mなら既存の`cleared`へ遷移する。終端状態から回復して再開させない。
- 同一更新で目標深度到達と燃料0が成立した場合は、既存仕様どおり`depleted`を優先する。

## 4. 決定的ロジックと責務

- `src/game/diveProgression.ts`に、終端判定と0〜100のclampを維持した燃料増減用の純粋関数を追加する。
- 新規`src/game/encounterRules.ts`に、出現予定の計算、円形重なり判定、無敵残り時間の更新、岩ダメージ可否をPhaser／DOM非依存の純粋ロジックとして置く。
- `GameScene`は純粋ロジックの結果を受けてGameObjectの生成、移動、破棄、HUD同期、ARIA通知だけを担当する。
- スケジュールは経過秒の境界を「直前より大きく、現在以下」で一度だけ返す。再開後や低fpsでも重複生成しない。
- GameObject、DOMイベント、タイマー、キーボードリスナーをScene終了時に残さない。

## 5. 見た目とフィードバック

- 岩は暗い不規則多角形、低不透明度の陰影、警告色の細い輪郭で描く。写真、生成画像、外部画像、実在生物に似せた輪郭を使わない。
- 回復カプセルはミント色の細い枠、短い電池形、`+`記号で描き、色だけに依存せず回復物と分かる形にする。
- 衝突時は艇の輪郭を短く警告色へ変え、`HULL IMPACT / FUEL -10`を画面上部の小さなイベント表示へ約1.1秒出す。画面揺れは使わない。
- 回復時は`FUEL RECOVERED / +25`、満タン時は`FUEL FULL / 100%`を同じ位置へ表示する。
- イベント表示はHTMLの`role=status`／`aria-live=polite`を持ち、320×568でもHUD、停止／音声ボタン、操舵環と重ならない。
- `prefers-reduced-motion: reduce`でも岩と回復の移動は攻略に必要なため止めない。点滅や脈動だけを省き、状態文言と燃料数値は常に更新する。

## 7. テストと受け入れ基準

- 燃料増減は100超過と0未満をclampし、低燃料への岩ダメージで`depleted`になる。
- 岩衝突直後は無敵時間が1秒となり、その間の追加ダメージを拒否する。時間は0未満にならない。
- 出現予定は境界前には0件、境界をまたぐと1件、長い更新で複数境界をまたぐと欠落なく時刻順に返り、同じ境界を再取得しない。
- 円形判定は接する境界を衝突とし、境界外を衝突としない。
- 320×568で潜航を開始し、中央に留まると最初の岩で燃料が約10減り、イベント表示が出る。その後、中央の回復カプセルで燃料が増える。
- 艇を動かして岩を避けられ、回復カプセルへ接触して回収できる。
- 一時停止中に深度、燃料、岩、回復、無敵時間、出現スケジュールが変化せず、再開後に継続する。
- HUDと操作UIに重なりがなく、公開ページのコンソールにゲーム進行を妨げるエラーがない。
- `npm run typecheck`、`npm test`、`npm run build`、`git diff --check`が成功する。
